# Plan: Refactor Timebeing hierarchy + Inquirer + Interfaces

## Goal
- Create `Timebeing` base class (tbid, tbn only) in `chronomatter.py`
- Make `Calendar` extend `Timebeing`
- Split `Chronomatter` into `ChronomatterV1` and `ChronomatterV1Serial`, both extending `Calendar`
- Add `Inquirer` mixin with `verify(content, fortis)` that uses `_lookup_key_for_tick` to get surrounding ticks and calls appropriate `_verify_*` function
- Define ABC interfaces: `CalendarInterface`, `ChronomatterInterface`, `InquirerInterface`
- Wire `TimeFamily` to expose `calendar()`, `chronomatter()`, `inquirer()` returning interface objects
- Move `stamp_tbid` from `TimeFamily` onto `Calendar`
- Fix broken `.stamper` imports

## Architecture

```
Timebeing (base, chronomatter.py)
├── tbid: bytes
├── tbn: str
└── family: TimeFamily | None  # set after construction

Calendar (extends Timebeing, calendar.py)
├── _ticks, stamp_tbid
├── append(), get(), latest(), save(), load(), integrity_check(), ticks property
└── inherits tbid, tbn, family from Timebeing

ChronomatterV1 (extends Calendar, chronomatter.py)
├── Non-serialized daemon — ticks every chronon_ns
├── stamp(), tick(), get(), attach_calendar(), shutdown()
└── No serialized flag, no if-then branches

ChronomatterV1Serial (extends Calendar, chronomatter.py)
├── Throttled daemon — wakes every 100ms, ticks on schedule
├── Same public API as V1
└── _next_tick_time_ns managed in __init__

Inquirer (extends Timebeing, chronomatter.py)
├── Standalone Timebeing — NOT a mixin, NOT extending Calendar
├── verify(content, fortis)
│   └── Receives list of calendars from TimeFamily
│   └── Finds matching tbid's calendar from the list
│   └── _lookup_key_for_tick returns TWO surrounding ticks
│   └── If both found → call _timebeing._verify_pair (chain verify)
│   └── If only one found → call _timebeing._verify (single key lookup)
└── Has its own tbid/tbn/family like any other time being

ABC Interfaces (at top of chronomatter.py)
├── CalendarInterface — Protocol for Calendar
├── ChronomatterInterface — Protocol for ChronomatterV1/V1Serial
└── InquirerInterface — Protocol for Inquirer

TimeFamily (time_family.py)
├── Creates Calendar + ChronomatterV1/V1Serial + Inquirer as 3 separate instances
├── Sets each instance.family = self (circular ref OK, weakref optional)
├── Sets calendar.stamp_tbid = chronomatter.tbid on attachment
├── Passes [calendar] list to Inquirer so it can look up keys
├── Exposes calendar(), chronomatter(), inquirer() → return interface wrappers
└── Dormant load uses ChronomatterV1Serial.__new__()
```

**Key implementation detail — `_lookup_key_for_tick`:**
- Returns `(prev_tick: TickRecord | None, next_tick: TickRecord | None)` instead of just `bytes | None`
- Searches internal `_tick_pks` list to find the tick record at that counter index
- Caller (`Inquirer.verify`) decides which `_verify_*` to use:
  - Both present → chain verify via `_timebeing._verify_pair(next, prev, tbid)` then signature check
  - Only one present → single-key verify via `_timebeing._verify`

### 3. `src/fortias/time_family.py` — Major refactor

**Before:** Creates `Chronomatter(serialized=...)` + `Calendar()`, attaches them.
**After:** Creates `Calendar()` + chooses `ChronomatterV1()` or `ChronomatterV1Serial()`.

```python
class TimeFamily:
    def __init__(self, ..., serialized=False, persist_path=None):
        self._calendar = Calendar(tbid=..., tbn=...)
        if serialized:
            self._chronomatter = ChronomatterV1Serial(...)
        else:
            self._chronomatter = ChronomatterV1(...)
        self._chronomatter.attach_calendar(self._calendar)
        self._calendar.stamp_tbid = self._chronomatter.tbid
        self._inquirer = Inquirer()  # or mixed-in approach

    def calendar(self) -> CalendarInterface:
        return _CalendarWrapper(self._calendar)

    def chronomatter(self) -> ChronomatterInterface:
        return _ChronomatterWrapper(self._chronomatter)

    def inquirer(self) -> InquirerInterface:
        return _InquirerWrapper(self._inquirer)
```

**Dormant loading:** Uses `ChronomatterV1Serial.__new__()` (never stamps = no-op behavior).
